# data/facts/ — 사실 표

**여기 있는 CSV는 커밋된다.** `data/` 의 다른 곳과 다르다.

원문이 아니라 **사실**이고, 스키마·분류·문장화는 우리가 만든 것이다 (D-37).
4명이 나눠 쓴 것을 병합하려면 저장소를 거쳐야 하고, 재현성에도 필요하다.

```
사실표_양식.csv     복사해서 쓰는 원본 + 예시 3행. 여기에 직접 쓰지 않는다
facts_ohb.csv       오한빈
facts_lgj.csv       이근준
facts_lse.csv       이서은
facts_ksr.csv       권소라
```

**각자 자기 파일에만 쓴다.** 한 파일을 넷이 고치면 충돌한다.

## 작성 전에

작성법은 **`docs/01e_사실표작성지침.md`** 를 먼저 읽는다. 특히 3장(`threshold_type`)은
여기서 틀리면 트리아지 규칙 테이블이 통째로 틀어진다.

## 커밋 전에

```bash
python scripts/check_facts.py data/facts/facts_ohb.csv
```

ERROR 가 0이어야 커밋한다. 검사가 잡는 것:

- 필수 칸 결측 · 허용값 오타
- **수치가 있는데 `threshold_type` 이 빈 행** — 역치로 오인된다
- **조류인데 `dose` 가 채워진 행** — 코퍼스에 조류 체중당 임계치는 0건이다
- **`MONITOR` 인데 상승 조건이 빈 행** — 조건 없는 관찰은 과소평가다
- **경로 ② 자료인데 `quote` 가 채워진 행** — 원문을 적재하지 않는다
- `fact_id` 중복 · 같은 물질의 급여 등급 불일치

## 이 표가 어디로 가나

```
사실 표 ──[templates.py]──→ 우리 문장 ──→ 청킹 ──→ 벡터DB
        └──[D-09]────────→ 트리아지 규칙 테이블
```

문장화는 코드가 한다 (D-38). **표가 맞으면 문장도 맞는다.**
