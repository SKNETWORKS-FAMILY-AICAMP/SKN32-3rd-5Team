**확인할 것**

- 숫자와 **단위**가 원문과 같은가 (`mg/kg` ↔ `g/kg` 은 1,000배)
- 원문이 그 숫자를 **역치로 서술**하는가, 아니면 *"reported to cause"* 인가

### 1.1 ✅ 해결 — 남천·체리로렐의 `2-2.5 mg/kg` 은 식물 용량이 아니었다

`F-098-011` · `F-098-014` 의 수치는 **시안화수소(HCN) 기준**이다.
남천 열매 몇 g이 아니라 거기서 방출되는 HCN 량이다.

> **이대로 규칙 테이블에 넣으면 "남천 2mg/kg 섭취 시 치사"가 되어 완전히 틀린다.**
> 남천 열매의 HCN 함량을 모르면 체중당 섭취량으로 환산할 수 없다.

`F-098-012` 남천(베르베린) `100 mg/kg` 은 **8~10일 반복 투여** 실험값이다.
단회 섭취 임계치가 아니다.

**원문 대조 결과** — *"Lethal HCN dose: 2-2.5 mg/kg body weight (**most species**)"*.
확정이다. 세 행을 `threshold_type=기타` 로 내리고 `substance` 에 `(HCN 기준)` 을 붙였다.
**규칙 테이블에서 빠졌다.**

### 1.2 단위가 개수인 4행

`seeds` · `leaves` · `drupes` · `알`. 계산 노드가 **체중당으로 환산할 수 없다.**

| fact_id | 값 | 문제 |
|---|---|---|
| `F-098-006` | 소철 씨 **2개** | 견종 체중이 안 들어간다 |
| `F-098-008` | 백합 잎 **1-2장** | 상동 |
| `F-098-010` | 멀구슬나무 열매 **5-6개** | 원문이 "소형견 기준"이라 명시 |
| `F-034-013` | 포도 **4-5알** (체중 8.2kg 개) | 체중이 note에만 있다 |

**→ 처리됨**: `build_rule_table.py` 가 `computable=N` 으로 표시한다.
계산 노드는 이 행을 **건너뛰고 정성 문장으로만** 답해야 한다.
`F-098-010` 멀구슬나무는 원문이 *"Toxic dose not clearly established"* 라고 명시해
`증례 보고 범위` 로 내렸고 규칙 테이블에서 빠졌다.

### 2. ✅ 해결 — 규칙 테이블을 사실 표에서 파생하도록 바꿨다

`compute/tables/사실표_초안_정량임계치.csv` 를 사람이 따로 유지하다가
**마카다미아 0.7 g/kg 이 `임상징후 발현` 으로 잘못 적혀** 있었다.
사실 표에서는 고쳤는데 초안은 그대로여서 **두 출처가 공존**했다.

**초안 CSV를 삭제하고 `scripts/build_rule_table.py` 로 파생시킨다.**

```bash
python scripts/build_rule_table.py --write   # → compute/tables/정량임계치.csv
```

편입 기준은 `templates.THRESHOLD_TYPES` 를 **그대로 가져다 쓴다** —
문장에 *"N 이상 섭취 시"* 로 나가는 것과 규칙 테이블이 어긋날 수 없다.
사람이 쓰는 데이터는 이제 `data/facts/facts_*.csv` **하나뿐이다** (D-22).

생성물에 `computable` 열이 붙어 **계산 불가 3행이 표에서 스스로 드러난다.**

## B. 답변 내용을 틀리게 만드는 것

### 3. 자료 간 충돌 — 검색에서 함께 나온다

#### 3.1 ✅ 해결 — `F-095-005` 국화(고양이)는 **원문 복붙 오류가 맞았다**

홍콩 AFCD 고양이 자료에서 「菊花(국화)」 항목의 본문이 바로 위 「百合花(백합)」 항목과
**글자 그대로 같다** — *"對貓來說是第一劇毒…昏迷甚至死亡"* (고양이에게 최고 독성, 혼수·사망).

- 같은 기관의 **개 자료**(`F-096-002`)는 국화를 위장관 증상·피부염으로만 기술한다
- **ASPCA**(S-008)도 국화를 백합급으로 두지 않는다

**원문 대조 확정** — AFCD 25-26행이 16-17행과 **글자 하나 안 틀리고 동일**하다.
주변 항목(`富貴竹`·`萬年青`)은 각각 다른 서술을 갖는다. **국화만 백합 문장을 복사했다.**

원문은 고치지 않되 **백합급 서술이 문장으로 나가지 않게** `effect`·`signs` 를 비웠다.
문장은 이제 *"국화는 고양이에게 독성이 있다."* 만 나온다.
국화의 독성 자체는 **ASPCA `F-008-043`** 이 뒷받침한다.

#### 3.2 초콜릿 등급이 자료 하나에서만 다르다 ✅ 해결

코퍼스 21행 중 **20행이 `NEVER`** 인데, 일본 환경성(`F-097-005`·`F-097-006`)만
원문이 초콜릿을 `注意が必要`(주의) 절에 두었다. 서브에이전트가 **그 두 행만 등급을 비워** 두었다.

**→ 결정 (2026-08-01, 팀장)**: **비워 둔 채로 둔다.**
원문(일본 환경성)이 초콜릿을 `注意が必要` 절에 두었을 뿐 등급 표기를 하지 않았다.
**원문에 없는 등급을 사람이 채우면 그게 환각이다** (D-30 · D-38).
정량 판정은 같은 물질을 `mg/kg` 역치로 다루는 **S-034(`F-034-020~022`)** 가 담당하므로
이 두 행이 비어 있어도 개 초콜릿 질의는 계산 노드가 답할 수 있다.
병합 WARN 은 뜨는 것이 맞다 — **자료마다 서술이 다르다는 사실 자체가 정보다.**

#### 3.3 백합 — 개와 고양이의 위험도가 다르다

| | |
|---|---|
| `F-098-008` 고양이 | 신독성. **잎 1-2장으로 급성 신부전** |
| `F-098-009` 개 | **신독성 없음.** 다량에서 경도 위장관 증상만 |

**종 구분 없이 답하면 개 보호자에게 과잉 경보**가 된다. `F-096-011`(AFCD 개)이 같은 방향이다.

그리고 **ASPCA 개 목록에는 진성 백합(Lilium)도 원추리(Hemerocallis)도 한 항목도 없다.**
절단 탓이 아니라 원래 없다 (L 구간은 온전하다). 고양이 목록에는 7종이 있다.

`F-098-016` **칼라(Arum Lily)** 는 원문이 *"NOT nephrotoxic (unlike true lilies)"* 라고 명시한다.
이름 때문에 진성 백합과 묶이면 오답이다.

뺀 자리에는 *"가까운 동물병원이나 24시 동물병원으로 바로 연락해 주세요"* 가 붙고,

### 4. 단위·수치가 어긋난 곳

#### 4.1 건포도 — 본문 `mg/kg` vs 표 `g/kg` (1,000배)

| fact_id | dose | unit | 근거 |
|---|---|---|---|
| `F-034-008` | 2.8 | **mg/kg** | 본문 p.2 *"as low as 2.8 mg/kg (31)"* |
| `F-034-009` | 2.8-36.4 | **g/kg** | Table 1 — **같은 참고문헌 (31)** |

같은 출처를 논문이 두 단위로 적었다. 환산·선택하지 않고 두 행 다 남겼다.

#### 4.2 S-043 영양표준

| 항목 | 내용 |
|---|---|
| **성장기 이중값** | 반려견 표는 `초기 성장(14주 미만)·번식` / `후기 성장` 두 열이다. `dose` 에 **초기 성장(높은 쪽)** 을 넣었다 — 이 규칙이 맞는지 |
| **`F-043-045` 칼슘** | 최대가 `6.25(4.5)d` — 각주 d는 **31.75kg 이상 성장 견종 자견은 4.5**. 계산 노드가 견종 체중으로 분기해야 한다 |
| **`F-043-046` 인** | 성견 표엔 최대 4.00 이 있는데 성장기 표엔 없다. 원문 그대로 비웠다 |
| **FEDIAF·AAFCO 불일치 44행** | 성묘 라이신 **2.4배** · 아라키돈산 **3.3배** · 나트륨 2.6배. **aNIAS 값을 채택**했고 나머지는 note |
| `F-043-003` | 원문 `RER = 1.25 × BER` — **문서 어디에도 BER 정의가 없다.** BMR 오기 가능성 |
| `F-043-010` | illness factor 1.0–1.5 는 **폐기된 과거 계수**. 계산 노드가 집어가면 안 된다 |

#### 4.3 S-044 사료성분표

- `F-044-026` **어유 조지방 100.71%** — 100을 넘는다. 원문대로 옮겼다

### 7. 조류 — 등급 근거가 없다

조류 159행 중 `triage_level` 이 있는 것은 **25행뿐**이고, 그마저 PTFE 흄·외상·발작 등
**응급 상황**에서 왔다. **중독으로 EMERGENCY 를 낼 근거가 0건이다.**

새로 넣은 학술 문헌 3건(S-070·S-093·S-094)은 **임상의 대상**이라 보호자 행동 지시가
한 건도 없어 64행 전부 등급이 비었다.

> **골든셋에서 조류 중독에 `EMERGENCY` 를 정답으로 쓰면 통과할 수 없다.**
> 이건 데이터 문제가 아니라 **설계 공백**이다.

체중당 수치 11건이 나온 건은 **D-09 후속에 기록**했다 — 결정은 유지한다.
