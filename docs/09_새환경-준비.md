작성자: **오한빈(팀장)** · 2026-08-03

저장소를 새로 받으면 **세 가지가 없다** — 파이썬 환경 · API 키 · 벡터 인덱스.

> 🔴 **셋 다 없어도 서버는 뜨고 평가도 돈다. 그리고 전부 거절로 집계된다.**
>
> 2026-08-02 실측 — `langgraph` 가 없는 환경에서 서버가 **정상 기동**했고 모든 질의가
> `판정불가` 로 나갔다. HTTP 200 이었다. *"시스템이 다 거절해요"* 만 보이고 원인은
> 안 보인다 (D-64). **조용히 반쯤 도는 것이 가장 나쁘다.**

그래서 **먼저 점검하고 시작한다.**

```powershell
python scripts/doctor.py
```

무엇이 없고 무엇을 하면 되는지 한 줄씩 나온다. **고쳐 주지는 않는다** —
설치·적재는 시간과 디스크를 쓰는 일이라 사람이 정한다.

## 2. 파이썬

**3.11** 을 쓴다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1

$env:PYTHONUTF8="1"                                    # 🔴 아래 참조
pip install -e '.[api,rag,ingest,db,dev]' -c constraints.txt
```

> 🔴 **`db` 를 빠뜨리지 않는다.** 없어도 설치는 성공하고 `pytest` 도 초록으로 끝난다.
> 대신 `tests/test_auth_api.py` 가 **모듈째 건너뛰어진다** — 회원가입·로그인·반려동물
> 프로필 **25건이 안 도는데 요약줄에는 `1 skipped` 로만 보인다.** 2026-08-03 실측 —
> `db` 없이 `518 passed, 1 skipped` 를 보고 *"머지 안전"* 으로 읽었는데, 그 머지가
> 바꾼 것이 바로 `routes/pets.py` 였다.
>
> **`1 skipped` 를 한 건으로 읽지 않는다.** 모듈 단위 스킵은 파일 하나가 통째로
> 빠진 것이고, `test_auth_api.py` 머리말이 그 위험을 이미 적어 두었다 —
> *"이 테스트가 없으면 이 코드는 CI 에서 한 줄도 실행되지 않는다."*

> 🔴 **`$env:PYTHONUTF8="1"` 을 먼저 세운다.** 파이썬이 파일을 읽을 때 인코딩을
> 안 정해 주면 **시스템 로캘**을 쓰는데, 한국어 윈도우는 그것이 `cp949` 다.
> 우리 문서·주석·표가 전부 한글이라 그 순간 터진다 — 2026-08-03 새 기기에서
> `pip install` 이 첫 줄부터 죽었다.
>
> ```
> UnicodeDecodeError: 'cp949' codec can't decode byte 0xed in position 16
> ```
>
> **리눅스 CI 는 UTF-8 이라 이 계열을 하나도 못 잡는다.** 그래서 이 한 줄이
> 팀원 PC 전용 방어다. 이 셸에서만 유효하므로, 매번 치기 싫으면 **시스템 환경 변수**에
> `PYTHONUTF8=1` 로 넣어 둔다.

> ⚠️ **`-c constraints.txt` 를 빠뜨리지 않는다.** 의존성이 서로를 끌어당겨
> 설치가 통째로 실패한 적이 있다 (`ResolutionImpossible`, D-74). 핀은 손으로 맞춘 것이
> 아니라 pip 에게 풀게 한 뒤 결과를 박은 것이다.
>
> 🔴 **`constraints.txt` 첫 줄의 `# -*- coding: utf-8 -*-` 을 지우지 않는다.** pip 은
> BOM 도 코딩 선언도 없으면 requirements 파일을 **시스템 로캘**로 디코딩한다.
> 한국어 윈도우(cp949)에서는 한글 주석에서 터지고, **리눅스 CI 는 UTF-8 이라 절대
> 안 걸린다** — 팀원 PC 에서만 설치가 실패한다 (2026-08-03 실측).

`.[qwen]` 은 로컬 Qwen(비교군 C·D) 용이고 **GPU 가 있을 때만** 의미가 있다.

## 3. 비밀

```powershell
python scripts/setup_env.py        # 만들고 **검증까지** 한다 (권장)
```

`setup_env.py` 는 `doctor.py` 와 보는 것이 다르다 — `doctor` 는 *"있나"*, 이것은
***"쓸 수 있나"*** 를 본다. 자리표시자·빈 값·중복 키·인코딩·**셸 변수가 `.env` 를
가리는 것**까지 잡는다 (D-94).

손으로 하려면 —

```powershell
Copy-Item .env.example .env
```

`.env` 를 열어 **두 줄**을 채운다.

```dotenv
OPENAI_API_KEY=sk-...
JWT_SECRET_KEY=       # python -c "import secrets; print(secrets.token_urlsafe(48))"
```

`DATABASE_URL` 은 `.env.example` 에 **SQLite 기본값이 들어 있으므로 그대로 둔다.**
설치가 필요 없고 스키마·코드는 MySQL 과 같다 — 드라이버는 코드가 아니라 URL 이 고른다.

> 🔴 **`JWT_SECRET_KEY` 를 비워 두면 로그인이 실패한다.** 약한 기본 키로 조용히
> 도는 것을 막으려고 예외를 낸다 (`JWTKeyMissingError`).
>
> ℹ️ `DATABASE_URL` 이 있으면 **`.[db]` 가 반드시 필요하다** — 없으면 앱이 기동을
> 멈춘다. §2 의 설치 줄에 `db` 가 들어 있으니 그대로 따랐다면 문제없다.

> 🔴 **`PETTRIAGE__MODEL__API_BASE_URL` 이 살아 있으면 주석 처리한다.** Gemini
> 엔드포인트에 OpenAI 키를 보내면 401 이다. 기본값이 이미 OpenAI 본가이므로
> **아무것도 안 적는 것이 맞다.**
>
> ℹ️ 키가 없어도 **`--arm none` 기준선은 돈다.** 코드·규칙 부분은 키 없이 검증된다.

## 5. 확인

```powershell
python scripts/doctor.py                    # 막히는 것 없음
pytest                                      # 585 passed, 22 deselected
python scripts/smoke_llm.py --arm A         # 키가 읽히나 (호출은 안 한다)
```

> 🔴 **`pytest` 에 `-q` 를 붙이지 않는다.** `pyproject.toml` 의 `addopts` 가 이미
> `-q` 를 넣으므로 손으로 하나 더 붙이면 **`-qq` 가 되어 `X passed` 요약줄이 사라진다.**
> 점만 찍히고 개수가 안 보인다 — 2026-08-03 에 이걸로 30분을 썼다.
>
> `22 deselected` 는 정상이다. `todo`·`gpu` 마커가 붙은 것들이고 `addopts` 가
> `-m 'not todo and not gpu'` 로 뺀다. **남은 일 목록은 `pytest -m todo` 로 본다.**
>
> ⚠️ `smoke_llm.py` 가 `클라이언트 none(폴백)` 을 찍으면 `.env` 의
> `OPENAI_API_KEY` 가 비어 있는 것이다. `.env` 는 커밋되지 않으므로 **새 클론에는
> 항상 비어 있다** — `.env.example` 을 복사만 하고 넘어가면 여기서 걸린다.

여기까지 통과하면 평가를 돌릴 수 있다.

```powershell
$env:PETTRIAGE_PROFILE="eval"
python eval/harness/run_eval.py --arm none --json eval/reports/확인_기준선.json
```

> 🔴 **`PETTRIAGE_PROFILE` 은 `.env` 에 적으면 안 먹는다.** 밑줄이 하나라
> 오버라이드로 안 잡히고 `get_config()` 는 셸 환경변수만 본다. **셸에서 세운다.**

## 6. 시연 (회원가입·다이어리까지 돌려 본다)

평가만 돌릴 것이면 여기는 건너뛴다. 화면을 띄울 사람만 한다.

```powershell
pettriage-initdb                            # → 테이블 준비 완료
uvicorn pettriage.app.main:app              # 다른 창에서. --reload 는 안 붙인다
```

`pettriage.sqlite3` 파일 하나가 저장소 루트에 생긴다. `.gitignore` 의 `*.sqlite3` 로
빠지므로 커밋에 딸려 가지 않는다. **MySQL 도 도커도 필요 없다.**

브라우저 없이 왕복만 확인하려면 —

```powershell
python -c "from fastapi.testclient import TestClient; from pettriage.app.main import create_app; c=TestClient(create_app()); c.post('/api/auth/signup',json={'email':'demo@a.co','password':'hunter22!','nickname':'demo'}); t=c.post('/api/auth/login',json={'email':'demo@a.co','password':'hunter22!'}).json()['access_token']; h={'Authorization':'Bearer '+t}; p=c.post('/api/pets',json={'name':'coco','species':'dog'},headers=h).json()['pet_id']; c.post('/api/records',json={'pet_id':p,'species':'dog','recorded_at':'2026-08-03T09:00:00'},headers=h); print(c.get('/api/report',params={'pet_id':p},headers=h).json()['timeline'])"
```

기록 1건이 담긴 목록이 찍히면 전체 앱이 SQLite 로 도는 것이다.

> ⚠️ **`uvicorn --reload` 는 붙이지 않는다.** 윈도우에서 `Ctrl+C` 가 안 먹어
> 터미널이 굳는다. 시연에는 필요 없다.
>
> ⚠️ **서버는 창을 따로 열어서 띄운다.** 작업용 창과 섞으면 위 문제가 반복된다.

MySQL 로 바꿀 때는 `.env` 의 `DATABASE_URL` 한 줄만 갈아 끼운다 (`docker compose up -d db`).
스키마는 `models.py` 가 이식 가능한 타입만 쓰므로 그대로 선다.

### 푸시 전에 CI 와 같은 검사를 돌린다

CI 는 `make lint` 를 부르지만 윈도우에는 `make` 가 없다. **`Makefile` 의 `LINT_PATHS`
와 같은 목록**을 직접 치면 된다 — 여기가 갈리면 CI 만 빨개진다.

```powershell
ruff check src tests scripts eval
ruff format --check src tests scripts eval
pytest
```

> ⚠️ `ruff` 버전을 임의로 올리지 않는다. `constraints.txt` 가 `ruff==0.8.6` 을 고정하고
> CI 도 `-c constraints.txt` 로 같은 것을 깐다. **포매터는 버전이 다르면 결과가 갈린다.**
> `make install` 로 깔았으면 이미 맞다.

## 측정할 때 지킬 것 (04 §8)

1. **커밋하고 잰다.** `provenance.dirty` 가 참이면 그 숫자는 남에게 줄 수 없다.
2. **`--arm` 을 쓴다.** 손으로 환경변수를 맞추면 빠뜨리고, 빠뜨리면 다른 조건으로
   재고도 모른다. `--arm` 은 `PETTRIAGE__MODEL__*` 를 **전부 비우고** 시작한다.
3. **기준선을 함께 낸다.** `--arm none` 이 없으면 *"LLM 을 넣은 의미"* 를 말할 수 없다.
4. ⚠️ **같은 커밋이라도 ±2건 흔들린다.** `temperature=0` 은 박혀 있으나 `seed` 를
   주지 않아 재현이 보장되지 않는다 (2026-08-03 실측 — 통과 26/27/28).
   **1~2건 차이를 개선으로 읽지 않는다.**

```powershell
python scripts/diff_reports.py eval\reports\A.json eval\reports\B.json
```

두 실행을 **케이스 단위로** 비교한다. 총계만 보면 *"틀리던 건이 거절로 빠져
등급 분모가 줄어 비율이 오른 것"* 을 못 읽는다 (04 §1.2).
