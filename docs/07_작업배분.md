### 골든셋은 기준선부터 만든다

넷이 동시에 쓰기 시작하면 **등급 판정 기준이 넷으로 갈린다.** 순서를 둔다.

```
① 이서은이 10건을 쓴다                 ← 오늘 밤 제일 먼저
② 팀장이 즉시 검수해 기준을 확정한다
③ 그 10건을 본보기 삼아 나머지가 착수한다   ← 그때부터 병렬
```

②가 끝나기 전에 나머지 셋이 대량으로 쓰지 않는다. 기준이 바뀌면 다시 써야 한다.

> 🔒 표시는 **안전 직결** 노드다 — `triage.py` 는 하향 금지 게이트(D-09),
> `verify.py` 는 근거 검증(D-13 과소평가율). 이 둘은 검토를 한 번 더 받는다.
>
> 참고로 `compute.py` 는 정량 임계치 테이블에 붙으므로 **사실 표를 만드는 사람이
> 문맥을 가지고 있다.**

정하고 나면 이 표의 담당 칸을 채워서 커밋한다.

| 할 일 | 담당 | 완료 기준 |
|---|---|---|
| 학습 데이터 형식·프롬프트 확정 | 이서은 | 03 §2 |

**학습 실행은 나누지 않는다.** 병목이 사람이 아니라 GPU다 — 3080 한 대와 RunPod 이라
실행자를 늘려도 시간이 안 줄고, 두 사람이 각자 어댑터를 만들면 **어느 설정에서 나온
결과인지 추적이 안 된다.** D-41 의 *"재현은 `configs/` + `constraints.txt` + 시드로 한다"*
가 실행자 한 명을 전제한다.

**데이터 생성은 CPU 작업이라 나눌 수 있다.** 이서은이 형식을 확정하면
손이 빈 사람이 분량을 나눠 만든다.

**단일 실패 지점 걱정은 이미 대비돼 있다** — D-21 이 *"대형 LLM 기준 RAG 를 먼저 완성한 뒤
sLLM 으로 교체"* 다. 파인튜닝이 실패해도 시연은 된다. 보험은 사람을 더 붙이는 게 아니라
그 순서다.

**3080 은 디버깅용**(`PETTRIAGE_PROFILE=train-local`), **본 학습은 RunPod**(`train`).
프롬프트는 `models/prompts.py` 에 이미 있고 **학습과 추론이 같은 문자열을 쓴다** — 건드리지 않는다.

학습 진입 시 **골든셋 누수 검사**가 먼저 돈다. 학습셋과 평가셋이 겹치면 학습이 중단된다.

#### 사진 업로드는 마지막이다 (D-43)

00 §3.3 우선순위상 **2단계**다. 1단계(트리아지 QA)가 끝나기 전에 손대지 않는다.
착수하게 되면 순서는 이렇다 — **저장 전에 전부 코드가 한다.**

```
① 확장자·MIME·크기 검사   → 이미지 아니면 거부
② EXIF 전량 제거          → GPS·기기·시각. 원본 EXIF 보관 안 함
③ 얼굴 검출              → 1건이라도 있으면 저장 거부 + 이유 안내
④ 리사이즈 + 재인코딩     → 잔여 메타데이터 차단
⑤ 내부 UUID 로 저장       → 원본 파일명 버림
```

**사진은 LLM에 넣지 않는다.** 기록의 첨부물이지 판정 입력이 아니다 (D-11).

## 4. 서로 기다리지 않게 하는 규칙

```
사실 표(팀장) ──→ 적재 → 검색 ──┐
그래프 노드(팀장·이근준) ───────┼──→ 통합 → 평가(팀장)
골든셋(전원) ───────────────────┘        ← 아무것도 안 기다린다
화면(권소라) ───────────────────┘        ← 계약이 고정돼 있어 안 기다린다
```

**막힐 때 할 수 있는 일**

| 막힌 것 | 대신 할 일 |
|---|---|
| 사실 표가 아직 없다 | 그래프 노드 (`InMemoryStore` 로 테스트가 돈다) · 골든셋 · 화면 |
| 그래프가 아직 없다 | 화면 (`StubEngine` 이 계약대로 응답한다) · 골든셋 |
| GPU 가 아직 없다 | 학습 데이터 생성 (CPU 로 된다) · 골든셋 |
| API 가 아직 없다 | `index.html` 을 열어 목 데이터로 화면부터 |

**골든셋이 모두의 대기 시간 흡수처다.** 막히면 자기 25건을 채운다.

| 단계 | | 시간이 모자라면 |
|---|---|---|

| 3. 킬러 — 기간 리포트 | 코어 완성 후 | |
| 4. 부가 — 영양 정량 | 여유 시 | 가장 먼저 뺀다 |

> **네 개가 다 60%인 것보다 하나가 100%인 편이 점수가 높다.**
