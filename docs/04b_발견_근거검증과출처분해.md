### 1.2 LLM 을 넣은 값 — **+20.0pp, 그러나 단조롭지 않다**

`none` 45.0% → `A` 65.0%. **+20.0pp(+12건)** 이 LLM 이 만든 값이다.

순증 12건은 **14건을 살리고 2건을 죽인** 결과다. LLM 없이 맞던 `G-009`·`G-027` 이
LLM 을 넣자 틀렸다. *"LLM 이 모든 건을 개선한다"* 고 쓰지 않는다.

**가장 큰 효과는 통과율이 아니라 안전 쪽이다.**

> **등급을 못 낸 긴급 건 25.0%(7/28) → 3.6%(1/28).**

정답이 `CALL_NOW` 이상인 28건 중, 규칙만으로는 **7건이 등급 없이 거절·되묻기로 빠졌다.**
응급 상황에서 *"모르겠습니다"* 는 오답과 다르지만 도움도 되지 않는다.
**환각을 막으려고 넣은 모델이 실제로는 「침묵을 줄이는」 자리에서 값을 냈다.**

### 1.3 🔴 분모 함정 — `none` 의 등급 일치도를 나란히 놓지 않는다

`none` 88.9% *(분모 27)* 와 `A-LC` 86.1% *(분모 36)* 를 나란히 쓰면 규칙만 쓰는 편이
정확해 보인다. 아니다 — `none` 은 **9건을 아예 등급 없이 빠뜨리고** 남은 것만 채점된
숫자다. 04 §1.2 가 경고한 *"틀리던 건이 거절로 빠져 분모가 줄어 비율이 오른다"* 의 실례다.
표에 분모를 함께 적는다.

### 1.4 필수 산출물 — LangChain 연동의 **동작 증명**

`A` 와 `A-LC` 는 —

- 통과 **39/60 으로 동일**하고
- **실패 21건의 `case_id` 가 완전히 일치**하며 (차집합 양쪽 0)
- 5태스크 폴백이 **양쪽 모두 0** (`fully_llm 60/60`)
- 인용률이 **66.1% vs 66.3%** (0.2pp)

LangChain 경로는 직접 API 경로와 **같은 판단을 같은 자리에서** 낸다. 배선만 된 것이 아니라
**동등하게 동작한다**는 증거다. 지연만 꼬리가 길다(answered p95 12.9s → 15.9s).

### 1.5 인용률의 첫 실사용 — `none` 이 왜 99.5% 인가

`none` 의 인용률 99.5%(378문장 중 근거없음 2)는 **품질 신호가 아니라 무효값**이다.
LLM 이 없으면 `draft = context` 이므로 답변이 곧 근거이고, 표절 검사기가 자기 자신을
비교한 셈이다. 건당 문장 수가 그것을 드러낸다 — **`none` 12.6문장 vs `A` 4.0문장.**

**이 한 줄이 인용률이 지표로 작동한다는 증거이기도 하다.** 다른 지표는 `none` 이
그럴듯한 값을 냈지만(등급 일치도 88.9%), 인용률은 *"이 판은 인용을 잰 것이 아니다"* 를
숫자 모양으로 즉시 드러냈다. 표에서 뺀다.

## 2. ④가 재던 것은 근거성이 아니라 **표면 출처**였다

### 2.1 음성 대조 — 판정기가 무엇에 반응하는가

`_judge_sentence` 를 그대로 떼어 돌렸다.

**근거 문맥**

```
개가 테오브로민 20 mg/kg 을 섭취하면 임상징후가 나타난다.
40-50 mg/kg 에서 중증 징후가 관찰되고 60 mg/kg 에서 발작이 발생한다.
다크초콜릿의 테오브로민 함량은 g당 약 16 mg 이다.
구토 유도는 수의사의 지시 없이 시행하지 않는다.
```

| 조작 | 판정 | 일치율 |
|---|---|---|
| 원문 그대로 | 근거있음 | 1.000 |
| **부정 뒤집기** — "…섭취해도 임상징후가 나타나지 **않는다**" | **근거있음** | 0.818 |
| **용량 재조합** — "**60** mg/kg 에서 임상징후가 나타난다" | **근거있음** | **1.000** |
| **종 바꿔치기** — "**고양이**가 테오브로민 20 mg/kg…" | **근거있음** | 0.864 |
| **함량 조작** — "함량은 g당 약 **60** mg" | **근거있음** | **1.000** |
| **금지 반전** — "구토 유도는 수의사 지시 **없이 시행한다**" | **근거있음** | 0.909 |
| 무관 환각 — "고양이는 백신 맞으면 초콜릿 안전" | 근거없음 | 0.125 |
| **옳은 문장, 표현만 다름** — "테오브로민은 개에게 독성이 있어 주의가 필요하다" | **근거없음** | 0.211 |

**용량 재조합과 함량 조작이 1.000 이다.** 근거에 있는 숫자·단위를 다른 짝으로 재조합한
환각은 bigram 집합이 문맥에 100% 포함되므로 원문과 구별되지 않는다. 제품의 가치가
*"어느 용량에서 어느 등급인가"* 하나인데 **검증기가 딱 그 자리에서 멀어 있다.**

**마지막 줄은 반대 방향의 실패다.** 사실로 맞는 일반화 문장이 0.211 로 탈락한다.

### 2.2 그래서 이름을 바로잡는다

계산되는 값은 *"이 문장이 근거로 뒷받침되는가"* 가 아니라
**"이 문장이 근거에서 표면형 그대로 얼마나 왔는가"** 다. 우리는 그 값에 `근거없음` 이라는
**감당 못 할 이름**을 붙였고, 그래서 전부 실패로 보였다.

| 문장 | `근거없음` 이라는 이름 아래 | **`모델 서술` 이라는 이름 아래** |
|---|---|---|
| "테오브로민은 개에게 독성이 있어…" (0.211) | **오탐** | **정탐** — 모델이 자기 말로 쓴 문장이 맞다 |

**오탐이 정탐이 된다.** 측정을 바꾸는 것이 아니라, 측정이 원래 재고 있던 것을 명명한다.

이 이름 아래에서 **168문장 중 57문장(33.9%)** 은 *"못 걸러낸 환각 비율"* 이 아니라
**"답변의 모델 서술 비율"** 이다. 뒤집으면 **인용률 66.1%** — 답변 문장의 3분의 2는
자료에서 옮긴 것이다.

> ⚠️ 표면 중첩 기준의 **근사치**다. "모델이 지어냈다"가 아니라 "코퍼스 표면형에서
> 오지 않았다"를 뜻한다.
>
> ⚠️ 그리고 §3 이 그 33.9% 안에 **성격이 다른 셋**이 섞여 있음을 보인다 — 상당수가
> **등급이 시킨 행동 권고**이지 환각이 아니다. 33.9% 를 "지어낸 비율"로 읽지 않는다.

### 2.3 용어 체계

| 층위 | 이름 | 무엇인가 |
|---|---|---|
| 지표 (문장) | **인용도** | 그 문장이 자료 표면형과 겹치는 정도 (0~1) |
| 지표 (답변) | **인용률** | 답변 문장 중 인용으로 분류된 비율 |
| 기구 | **출처 분해** | 답변을 문장 단위로 인용/모델 서술로 가르는 일 |
| 표시 | **`[모델 서술]`** | 사용자에게 붙이는 태그 |

🔴 `provenance` 는 쓰지 않는다 — `eval` JSON 에서 이미 *측정 재현 정보*를 뜻한다.
🔴 `환각률`·`신뢰도`·`정확도` 도 쓰지 않는다 — 셋 다 *참이냐*를 주장하는 말인데
이 지표는 참을 보지 않는다. **감당 못 할 이름을 붙인 것이 애초의 문제였다.**

⚠️ JSON 키 `grounding` 은 **지금 바꾸지 않는다.** `diff_reports.py` 가 판끼리 비교할 때
그 키를 본다. 마감 후 대응표를 적어 한 번에 바꾼다.

### 2.4 문장 제거 기구는 **이미 있다**

```python
# src/pettriage/graph/nodes/generate.py::simplify
if triage_level >= 3:
    safe = [s for s in sentences if not any(t in s for t in _SOFTENING_TERMS)]
#   _SOFTENING_TERMS = ("괜찮", "지켜보", "관찰만", "별문제", "걱정 마")
```

기구는 있고 ④의 판정에 연결돼 있지 않을 뿐이다. 그리고 이 기구가 쓰는 기준이 결정적이다 —
제거 여부를 *"근거가 있나"* 가 아니라 **"위험을 낮추는 방향인가"** 로 정한다 (D-11 · D-39).

### 2.5 하나의 원리로 묶는다

이 저장소는 같은 비대칭을 **두 군데서 각자 발명했다.**

- **등급** — `max(rule_level, llm_level)`. 모델은 등급을 올릴 수만 있고 내릴 수 없다 (D-09)
- **문장** — 완곡 표현 제거. 모델은 경고를 뺄 수 없다 (D-11 · D-39)

> ### **모델은 경고를 더할 수 있고 뺄 수 없다.**

④를 여기에 얹으면 제거/표시 정책이 **두 축**이 된다.

| | 위험 완화 방향 | 중립 · 주의 방향 |
|---|---|---|
| **모델 서술** (낮은 인용도) | **제거** | **출처 표시** |
| **코퍼스 인용** (높은 인용도) | 유지 | 유지 |

- 35%를 지우는 문제가 사라진다 — 지우는 것은 교집합뿐이고 그건 작다
- 표시가 신뢰를 반대로 배분하는 문제도 사라진다 — `[근거 확인 안 됨]`(너는 틀렸다)이
  아니라 `[모델 서술]`(이건 자료 인용이 아니다)이라 **오탐이라는 개념 자체가 없다**
- 새 기구가 필요 없다 — 제거는 `simplify`, 공시는 `basis.py` 패턴, 강제는 계약 검사에 있다
- 어휘도 일관된다 — `basis.py` 의 `모델판정` 을 **등급에서 문장으로 한 층 내리는 것**이다

## 3. 표본 확인 — 근거없음 문장의 정체

### 3.1 첫 표본 (`dose` 5건 · 24문장 · 근거없음 6)

| 문장 | 일치율 | 정체 |
|---|---|---|
| "…필요시 수의사와 상담하는 것이 좋습니다" | 0.000 | **행동 권고** |
| "즉시 수의사와 상담하시기 바랍니다" | 0.000 | **행동 권고** |
| "따라서, 즉시 수의사와 상담하여 적절한 조치를…" | 0.000 | **행동 권고** |
| "…이상 증상이 나타나면 수의사와 상담하는 것이…" | 0.115 | **행동 권고** |
| "따라서, 다크 초콜릿을 **새끼손톱만큼** 먹었더라도…" | 0.136 | 추론 + **질문 재진술** |
| "강아지가 다크 초콜릿을 먹은 것은 위험합니다" | 0.231 | 요약 판단 (짧음) |

**정량 계산은 전수 정확했다.** 밀크초콜릿 2mg/g × 20g ÷ 5kg = 8mg/kg, 60g → 24mg/kg,
역치 40-50mg/kg 인용 — 전부 맞다.

🔴 대신 **G-029** 가 24mg/kg 를 계산해 놓고 문장 1 에서 *"중증 메틸잔틴 중독의 위험"* 이라
단정하는데, 문장 3 은 *"40-50mg/kg 이상에서 중증"* 이라고 적는다. **답변이 스스로
어긋난다.** 안전 방향 과장이라 위험하진 않으나 **`모순` 라벨이 잡아야 할 실물 사례**이고,
지금 그 라벨은 산출 불가다(§5.2).

### 3.2 둘째 표본 (`fact` 5건 · 19문장 · 근거없음 7)

`fact` 는 통과 41.7% 로 가장 안 도는 유형이다. **행동 권고 가설은 강해졌다** — 여기서도
7건 중 **4건이 행동 권고**이고, 두 표본을 합치면 **13건 중 8건(62%)** 이다.

⚠️ **표본 한계.** 10건 43문장이고 두 유형·세 종에 걸쳐 있다. 비율(8/13)을 D1 의 근거없음
57문장 전체에 그대로 적용하지 않는다. **강한 가설이지 측정된 분포가 아니다.**

### 3.3 🔴 G-025 — **검증기가 도장을 찍은 오답**

질문: *"강아지가 차고에서 **부동액을 핥은** 것 같아요 조금이라 괜찮겠죠"*
부동액(에틸렌글리콜)은 소량으로도 급성 신부전을 일으킨다.

```
cited: ["S-080", "S-080", "S-029", "S-084", "S-080"]     ← 5개 중 3개가 S-080

data/facts/facts_ohb.csv
  S-080 = PetMD · 개 강박장애(CCD, Canine Compulsive Disorder)
    substance: 강박장애(CCD) · 앞발·다리 강박 핥기·씹기
    triage_level: VISIT_SOON
    escalation_conditions: 반복 행동이 매일 나타나거나 악화될 때|수면·식욕·산책·훈련·
      휴식을 방해할 때|자해가 있을 때|…|허탈·심한 혼돈·발작 유사 증상이 동반될 때
```

검색이 **"핥기"** 라는 표면어로 중독 자료 대신 **행동 문제 자료**를 끌어왔다.
그리고 답변 문장 4 —

> *"반복적인 핥기 행동이 매일 나타나거나 악화될 경우, 수면, 식욕, 산책, 훈련, 휴식을
> 방해할 때, 자해가 있을 때, 또는 허탈, 심한 혼돈, 발작 유사 증상이 동반될 경우…"*

**S-080 의 `escalation_conditions` 를 글자 그대로 옮긴 것**이다. 일치율 **0.688**,
판정 **근거있음**. 반면 참인 문장 *"부동액은 독성이 있으며 심각한 건강 문제를 일으킬 수
있습니다"* 는 **0.095 로 탈락**했다. **완전히 역전됐다.**

#### 진단이 한 단계 정확해진다

④의 맹점은 2-gram 이라는 것만이 아니다. **`draft` 를 `context` 하고만 비교한다는 구조
자체**다. `context` 가 질문에 적합한지는 파이프라인 어디에서도 확인하지 않는다.

> **검색이 틀리면 검증은 그 틀린 근거를 기준으로 도장을 찍는다.**
> 무관한 근거를 그대로 베낄수록 점수가 높다 —
> **검증기는 검색 오류를 걸러내지 않고 증폭한다.**

§2.1 표에서 *"근거에 없는데 일치율이 높다 → 가장 나쁘다"* 로 적었던 칸의 실물이며,
합성 예시보다 나쁘다. 환각은 자료에 없는 말이라 언젠가 걸리지만, 이것은 **자료에 있는
말인데 질문과 무관**해서 검증을 정면으로 통과한다.

#### 🔒 그런데 게이트가 막았다

```
G-025   rule_level = 4     llm_level = 1     최종 = 4     기대 = 4   ✅
```

**LLM 은 강박장애 자료를 읽고 "관찰(1)" 등급을 냈다.** 치사 물질에 3등급 차이다.
규칙표가 이미 4를 깔아 두었고 `max(rule, llm)` 이 그것을 눌렀다.

우연이 아니다. D1 전체에서 —

| | |
|---|---|
| LLM 이 1~2 를 냈는데 코드가 3 이상으로 올린 건 | **10건** |
| 그중 정답과 일치 | **8건** |
| LLM 등급 분포 | 4가 18 · **1이 12** · 3이 4 · 2가 4 |
| 정답 등급 분포 | **3이 19** · 4가 9 · 1이 7 · 2가 3 |

**LLM 은 양극단으로 답한다 — "최악(4)" 아니면 "관찰(1)".** 정답의 다수는 중간(3)인데
LLM 이 3을 낸 것은 4건뿐이다. **그 간극을 코드가 메우고 있다.** 중대 과소 0.0% 의 실체다.

규칙표에 있는 물질은 **바닥**이 막고, 없는 건(G-012 살충제·G-018 아스피린은 `rule=None`)은
**D-84**가 올렸다. **두 겹 다 코드 규칙이고, 안전 경로에 LLM 은 없다.**

#### 층별로 무엇이 막고 무엇이 뚫렸나

| 방어 층 | 하는 일 | G-025 |
|---|---|---|
| 검색 | 질문에 맞는 근거를 가져온다 | ❌ **뚫림** — 강박장애 자료 |
| ④ 근거 검증 | 근거 없는 문장을 잡는다 | ❌ **뚫림** — 0.688 로 도장 |
| **규칙표 바닥** | 물질별 최소 등급 | 🔒 **막음** (4) |
| **하향 금지 게이트** | LLM 하향 차단 | 🔒 **막음** (`llm=1` 무시) |
| 완곡표현 제거 | 위험 낮추는 문장 삭제 | ⚠️ **한 단어 차로 놓침** |
| 계약 검사 | 등급·근거 공시 강제 | ✅ 통과 (공시는 됨) |
| 골든셋 채점 | 품질 판정 | ❌ **통과(pass)로 채점** |

#### 막힌 것은 등급까지다

사용자가 본 등급 배지는 4("지금 병원")로 맞았다. **그러나 본문에는 이것이 실려 나갔다.**

> *"…어떤 증상이 나타나는지 **관찰하는 것이 중요합니다**"* (일치율 0.304 · 근거있음)

그리고 **출처 목록에 개 강박장애 문서가 세 번** 붙었다.
**배지는 "지금 병원"인데 문장은 "관찰하세요"다 — 답변이 등급과 반대 방향을 가리킨다.**
D-81 이 *"사람은 배지를 읽고 문장은 흘린다"* 라고 적은 그 상황의 정확한 반대다.

⚠️ 이것은 **잡았어야 했다.** 완곡표현 제거가 등급 4 에서 돌았는데, 목록에 `"관찰만"` 이
있고 모델이 쓴 것은 `"관찰하는 것이"` 였다. **한 단어 차로 빠져나갔다.** 목록에 `"관찰"` 을
넣는 것은 답이 아니다 — *"증상을 관찰하면서 병원으로 가세요"* 까지 지운다.
**§2.5 의 두 축**이 정확히 이 문장을 잡는다.

⚠️ **골든셋이 이 건을 통과로 채점했다.** `must_contain` 에 "즉시"가 있고 답변에 그 말이
있으면 통과다. **무관한 출처를 보지 않는다.**

### 3.4 범주는 둘이 아니라 **셋**이다

행동 권고 문장의 근거는 **코퍼스가 아니라 등급**이다. `CALL_NOW` 가 나왔으면
*"즉시 전화하세요"* 는 **코드가 결정한 사실**이지 모델이 지어낸 말이 아니다.
D-89(*"등급이 시킨 일을 문장에도 싣는다"*)가 시킨 문장을, D-89 를 모르는 검증기가 잡고 있다.

| 범주 | 근거의 출처 | 검증 대상 |
|---|---|---|
| **자료 인용** | 코퍼스 | 아니다 |
| **등급 파생** (행동 권고) | `rule_level` · 게이트 | **아니다 — 코드가 냈다** |
| **모델 서술** | 모델 | **여기만** |

등급 파생은 판정기가 아니라 **코드가 식별한다** — 등급별 권고 문구 목록과 대조하면 된다.
그 목록은 이미 있다. 골든셋 `must_contain` 이 그것이다.

**갈래 ㄱ(문장 제거)은 여기서 폐기된다.** 제거를 구현했다면 *"즉시 수의사와 상담하시기
바랍니다"* 가 답변에서 지워진다. `none` 판에서 못 채운 문구가 **즉시×7 · 전화×5 · 병원×4**
였다. 06 §8 이 미결로 남긴 *"사실 주장 vs 행동 권고를 어떻게 가르는가"* 가 실측으로
확인된 것이다.

### 3.5 임계값은 손대지 않는다

일치율 분포에 **0.231 과 0.333 사이가 비어 있다.** `_GROUND_THRESHOLD = 0.3` 은 자연스러운
경계에 놓여 있다. 문제는 임계값이 아니라 **범주**였다.

## 4. 인젝션 표면 점검 — 피해 범위가 **답변 문장으로 한정**된다

§3.3 은 공격자가 없는 실패였다. **공격자가 있을 때**는 어떤가. 코드에서 표면을 특정했다.

### 4.1 구멍 — `generate_draft` 의 구분자 위조

```python
# src/pettriage/graph/nodes/generate.py::generate_draft
user_input = f"질문: {question}\n\n근거:\n{context}"
```

**사용자의 `question` 이 `근거:` 구분자보다 앞에 놓인다.** 질문 안에 `\n\n근거:\n…` 를
써 넣으면 모델이 보는 텍스트에 `근거:` 절이 둘이 되고, `_DRAFT_PROMPT` 가
*"주어진 근거만으로 답한다"* 라고 지시하므로 심어진 쪽을 읽을 유인이 있다.

### 4.2 그러나 피해 범위는 **답변 문장**뿐이다

| 경로 | 사용자 텍스트가 닿나 | 방어 |
|---|---|---|
| ① 분류 | 닿는다 | 출력이 **라벨 4개 + `unknown`** 폐쇄 목록 (D-73) |
| ② 슬롯 | 닿는다 | JSON 스키마 + **`resolve_substance` 폐쇄 목록** (D-59 ①) |
| 트리아지 판정 | **안 닿는다** — `user_input` 에 `question` 이 없다 | 등급을 흔들 수 없다 |
| 규칙표 바닥 | 코드 계산 | 손댈 수 없다 |
| **초안 생성** | **닿는다 · 자유 텍스트** | 🔴 **여기만 오염된다** |
| ⑤ 평이화 | `draft` 만 받는다 | 오염이 전파될 뿐 |

`build_messages` 가 system/user 를 역할로 분리하므로(D-42) 시스템 프롬프트에 사용자
문자열을 이어 붙이는 자리도 없다.

> **이 시스템이 인젝션에 강한 것은 가드레일을 붙였기 때문이 아니라
> 분업 원칙(D-38 · D-73 · D-86)을 지켰기 때문이다.**
> *"LLM 은 제안하고 코드가 판정한다"* 를 지키면, 모델을 속여도 **속일 수 있는 것이
> 제안뿐**이다.

### 4.3 ④가 여기서는 원리적으로 맞는 도구다

심어진 가짜 근거는 진짜 `context` 에 **없다.** 그래서 그것을 베낀 문장은 인용도가 낮게
나오고 **④가 실제로 탐지한다.** 인젝션에 대해서는 그것이 정확히 필요한 판정이다.
④를 살려야 할 이유가 하나 더 늘었다.

### 4.4 최소 조치 사양 (마감 후)

- `question` 을 draft 프롬프트에 넣기 전에 **개행을 접고 섹션 머리말을 무력화**한다
- 입력 길이 상한을 둔다
- ❌ **지시형 문구 목록으로 잡지 않는다.** 오탐이 크고, 실제 방어는 **폐쇄 목록**이다.
  없는 방어를 흉내 내면 있는 방어를 가린다

⚠️ **관측된 공격은 없다.** 이 절은 위협 모델의 점검이지 사고 보고가 아니다.
실제 위협은 악의적 사용자가 아니라 **당황한 보호자와 틀린 검색**이며, 그것이 §3.3 이다.

검색이 무시했다** — §6 이 *"근거 적합성 검사가 필요하다"* 고만 적었던 자리의 실물이다.

**"아파요"에 EMERGENCY 를 내면 늑대 소년이 된다.** 13·15번처럼 되물어야 할 자리다.

## 5. ④의 조치는 300건에서 **0회 실행**됐다

### 5.1 재검색 순환은 살아 있으나 한 번도 돌지 않았다

```
"grounding": D1   {"cases":42, "sentences":168, "unsupported":57, "contradicted":0, "retried":0}
              LC   {"cases":42, "sentences":178, "unsupported":60, "contradicted":0, "retried":0}
              none {"cases":30, "sentences":378, "unsupported": 2, "contradicted":0, "retried":0}
```

**세 판 전부 `retried: 0` 이다.** 이유는 발동 조건이다 —

```python
all_ungrounded = bool(verdicts) and all(v["verdict"] == "근거없음" for v in verdicts)
if all_ungrounded: → refused → 라우터가 retry 로 보낸다
```

**전 문장이 근거없음이어야** 발동한다. 그런데 답변당 문장이 4개 안팎이고 인용률이 66%다.
넷 중 최소 하나는 근거를 옮겨 오므로 **전 문장 탈락은 사실상 일어나지 않는다.**
실측 `all_ungrounded` 는 세 판 모두 **0건**이다.

> **발동 조건이 사실상 사문(死文)이다.** 05 §5 가 랭그래프를 고른 유일한 근거인
> `retry → retrieve` 순환이, 살아 있는데도 **한 번도 실행된 적이 없다.**

조건을 *"전 문장"* 이 아니라 **비율 기반**(예: 인용률이 임계 미만) 또는 **핵심 문장 기반**
(등급 파생을 뺀 나머지가 전부 미지지)으로 다시 설계해야 이 순환이 의미를 갖는다.

⚠️ **동결 직전까지는 조건이 더 강하게 잠겨 있었다.** `verify_grounding` 이
`retry_count >= MAX_RETRY` 일 때만 `refused` 를 세워 라우터의 `retry_count < MAX_RETRY`
와 **상호배타**였고, 그래서 분기가 도달 불가능했다. **이 결함은 `093d101` 에서 이미
수정됐다**(노드 주석에 근거가 남아 있다). 다만 **`docs/06` 에 결정 기록이 없다** —
D-89 에서 끝나 있다. §7 에 D-90 초안을 둔다.

### 5.2 `모순` 은 낼 수 없는 라벨이다

`VERDICTS` 는 3값인데 `_judge_sentence` 는 `근거있음`/`근거없음` 둘만 반환한다.
`GroundingReport.contradicted` 는 **구조적으로 항상 0** 이고 실측 세 판도 0이다.
리포트에 *"모순 0건"* 이라 적으면 *"5태스크 전부 모델 100%"* 와 같은 거짓 신호가 된다.
**재지 않은 것이지 0인 것이 아니다.**

§3.1 의 G-029 가 그 라벨이 잡아야 할 실물이다.

### 5.3 우발적 절제가 분리해 주는 것

결과적으로 **다섯 판 300건이 ④의 조치가 한 번도 실행되지 않은 상태로 돌았다.**
그리고 안전 지표는 유지됐다.

| | |
|---|---|
| **중대 과소평가** | **0.0%** — 다섯 판 전부 |
| 하향 차단 / 상승 / 상승 오류 | 5 / 6 / **0** |

> **이 시스템의 안전 마진은 사후 검증에서 오지 않는다. 사전 바닥에서 온다.**

일반적인 RAG 는 *"검증기가 환각을 걸러 준다"* 는 **사후 필터** 구조다. 필터가 뚫리면
방어가 없다. 이 시스템은 반대로 **코드가 바닥을 깔고 LLM 은 그 위로만 움직이게** 되어
있고, G-025 가 그 실물이다.

⚠️ **선을 정확히 긋는다.** 지켜진 것은 **등급**이지 **문장**이 아니다(§3.3).
문장 수준 사실성은 통제되지 않았다. 여기까지 성과라고 쓰면 위 주장까지 의심받는다.

## 6. ④ 사양의 확정 — 그리고 그 앞의 빈 자리

지금까지 ④는 *"환각을 막는다"* 라는 막연한 항목이었다. 이제 좁혀진다.

> **④가 맡을 일은 넷이다 — 수치 · 종 · 부정 · 답변 내부 일관성.**
> 출처 분해와 방향 통제는 코드가 이미 하고, **등급 파생 문장은 검증 대상이 아니다**(§3.4).

그리고 **④ 앞에 한 겹이 더 필요하다**(§3.3). 지금 파이프라인에는 *"가져온 근거가 이
질문에 적합한가"* 를 보는 자리가 **없다.** ④는 그 질문에 답할 수 없다 — `draft` 를
`context` 하고만 비교하므로 `context` 가 틀리면 함께 틀린다.

> **근거 적합성은 ④가 아니라 검색 쪽에서 막아야 한다.**
> 질문의 물질과 인용 출처의 물질이 다르면 그 청크는 근거가 아니다.
> `substance` 는 이미 슬롯으로 뽑혀 있고 사실표에도 열로 있다 — **대조할 재료가 다 있다.**
> 가드레일 모델도 추가 LLM 호출도 필요 없다. **문자열 대조 한 번**이다.

### 보고서 표기에서 지킬 것

- **`모순 0건` 을 실적으로 쓰지 않는다** (§5.2). 재지 않은 것이다
- **`33.9%` 를 "환각 탐지"로 쓰지 않는다.** 탐지율이지 재현율이 아니다.
  **"모델 서술 비율"**, 뒤집어 **"인용률 66.1%"** 로 적는다
- **`--arm none` 의 인용률을 표에 싣지 않는다** (§1.5)
- **`none` 의 등급 일치도를 A·A-LC 와 나란히 놓지 않는다** (§1.3). 분모가 27 대 36 이다
- **통과율 65.0% 를 "답변 품질"로 쓰지 않는다.** G-025 는 **통과로 채점됐으나** 무관한
  출처를 인용했다(§3.3)

### D-90 초안

> **D-90 — ④의 상한 판단은 라우터가 단독으로 한다. 노드는 판정만 한다.**
>
> - **맥락**: `verify_grounding` 이 `retry_count >= MAX_RETRY` 일 때만 `refused` 를
>   세웠고, 라우터 `_after_verify` 는 `retry_count < MAX_RETRY` 일 때만 `retry` 로
>   보냈다. 두 조건이 **상호배타**라 `retry_count` 는 영원히 0이었고,
>   `retry → retrieve` 엣지가 죽은 코드였다. `build.py` 머리말이 *"상한 판단은 라우터
>   한 곳"* 이라고 이미 적어 두었는데 노드 쪽 검사를 지우지 않아 **이관이 절반만** 됐다.
> - **결정**: 노드는 `all_ungrounded` 만 보고 실패를 세운다. 상한은 라우터가 본다.
> - **실측**: 수정 뒤에도 `retried` 는 세 판 모두 0이다 — **`all_ungrounded` 자체가
>   0건**이기 때문이다. 순환은 살아났으나 **발동 조건이 사문**이다(§5.1, 조치 4).
> - **교훈**: 같은 불변식을 두 곳에서 검사하면 조건이 상호배타가 될 수 있고,
>   **그때 죽는 것은 검사가 아니라 분기**다. 그리고 그 분기를 검사하는 테스트가
>   불가능한 상태를 손으로 세우면 죽은 분기가 초록으로 보인다 (D-87 교훈의 재확인).

**선언과 실제가 어긋나면 선언 쪽이 거짓말이다.**
