## 1. 연락처 차단(D-47)이 살아있는 응답 경로에 없다

`safety/contacts.py` · `graph/nodes/generate.py:50-69` · `app/engine.py`

`scrub_contacts` 의 **유일한 호출부는 `finalize` 하나**다(전체 grep 확인). `finalize` 는 `GraphEngine` 전용이고, `GraphEngine` 은 `NODES_IMPLEMENTED=False` 로 생성 자체가 막혀 있다. 지금 `/api/ask` 를 타는 것은 `StubEngine` 이고, 이쪽은 `AskResponse(answer=self._compose(...))` 를 **scrub 없이** 만든다.

## 3. `TriageResult` 가 게이트 결과를 무효화할 수 있다 (D-09)

`app/contracts.py:115-137`

`apply_gate()` 안의 산술은 완벽하다. 그런데 그 결과를 담는 `TriageResult` 에 **`level >= max(rule_level, llm_level)` 을 검사하는 검증기가 없다.**

```
apply_gate(EMERGENCY, MONITOR) -> level=4 overridden=True
TriageResult(level=1, rule_level=4, llm_level=1)  →  [통과]   ← 재현함
TriageResult(level=4, name="MONITOR", badge="관찰") →  [통과]   ← 등급/배지 불일치도 통과
```

D-09 우회 경로는 "게이트를 안 부르는 것"이 아니라 **"부른 뒤 결과를 덮는 것"** 이고, 계약이 그 문을 열어두고 있다. `name`·`badge`·`message` 도 `level` 과 무관한 자유 문자열이라 응답이 스스로 모순될 수 있다.
