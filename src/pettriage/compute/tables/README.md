## `threshold_type` 을 반드시 확인할 것

`증례 보고 범위` 는 **역치가 아니다.** S-034 Table 1의 g/kg 값들은
캡션이 *"Range of doses … reported to cause"* 이며, 실제로 용량-반응이 역전한다
(포도 3 g/kg 사망 vs 20.6 g/kg 회복).

`역치 없음` 은 원문이 용량-반응 미성립을 명시한 경우다 — 포도가 여기 해당한다.
이 물질은 **정량 판정을 하지 않는다.**

## 알려진 함정

- **건포도 단위** — S-034 본문은 `2.8 mg/kg`, 같은 논문 Table 1은 같은 출처를
  `2.8–36.4 g/kg` 로 쓴다. 원 출처(Eubig 2005)는 **g/kg**. 논문 자체의 오식이다.
- 조류 임계치는 **0건**이다. 조류 규칙은 `물질 × 증상` 정성 매핑으로 간다 (D-09).
